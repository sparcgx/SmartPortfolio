# 智投資 SmartPortfolio v1.6.4｜行情新鮮度與 iPhone PWA 驗收

股票、基金、交易、股息分析與定期定額試算的本機 React 管理工具。

## 直接使用

1. 解壓縮 ZIP。
2. Windows 可雙擊 `Start_SmartPortfolio_Windows.bat`。
3. 其他系統可直接以瀏覽器開啟 `SmartPortfolio_v1.6.4.html`。

這個單一 HTML 已內含程式與樣式。新增與修改資料會保存在目前瀏覽器的本機儲存空間；請固定使用同一個檔案位置與瀏覽器。即時行情連動需使用已發布的工作站網站，離線 HTML 會安全保留手動價格。

- 可安裝為 PWA，從 iPhone、iPad、Android 或桌面主畫面直接開啟
- 首次連線完成後可離線開啟，查看保存在本機的持股與交易資料
- 網站有新版時顯示明確更新提示，由使用者確認後才重新載入
- iPhone 安全區與主畫面 App 顯示最佳化
- 資產總覽、台股／美股／基金配置與前三大權重

- 買入、賣出、股息登記與交易履歷
- 可選擇今天或過去的實際交易日期，履歷依日期由新到舊排列
- 持股快捷加碼、賣出與股息登記，自動帶入既有標的資料
- 今天／昨天／自訂日期快捷選擇與儲存前交易摘要
- 交易表單只顯示必要欄位，產業、配息及備註可按需展開

- 最近一筆交易可從提示或交易紀錄頁立即復原
- 首次使用說明此瀏覽器的資料不會自動跨裝置同步；安裝 App 前顯示備份狀態
- 此裝置記錄備份下載時間與後續交易數，累積三筆新交易或備份超過七日且資料異動時提醒匯出；提醒可延後一天
- 手機版固定顯示快速登記交易按鈕
- 修正總覽摘要誤放在所有分頁共用區，造成選單已切換但看似停留總覽的問題
- 手機主選單改為五欄固定排列，避免左右裁切，並提高選取狀態對比
- 縮小手機快速交易按鈕並保留底部安全空間，減少遮擋內容
- 賣出數量檢查、加權平均成本與估算費稅
- 歷史補登按交易日期重算數量與平均成本；當時持股不足會阻擋賣出
- 舊交易與現有持股未對齊時，保留目前成本並提示核對；補齊相符的紀錄不會重複增加數量
- 補登舊交易保留現有行情／基金淨值；新標的的歷史成交價標示為待更新
- 依實際設定月份推估年度股息日曆
- 產業曝險分析與定期定額複利試算

- JSON 完整備份、檔案驗證與覆蓋前確認還原

- 台股上市／上櫃與美股股票／ETF 最新可用行情

## 重要說明

- 新安裝不含任何示範持股或交易資料。
- PWA 與一般瀏覽器分頁可能使用不同的本機儲存空間；安裝前請先匯出 JSON 備份。
- 離線模式只讀取最後保存在裝置上的資料；行情與匯率會在恢復連線後更新。
- 免費來源提供的是「最新可用」成交、收盤或參考資料，不保證為可交易報價。
- 自動來源無法辨識代號或暫時斷線時，系統會保留上次成功價格。
- 公募基金來源差異較大，目前請依基金公司公告手動更新淨值。
- 手續費、稅額、股息與複利結果皆為估算，實際金額以券商、基金公司及正式公告為準。
- 平均成本延續既有版本的成交價加權算法；估算手續費另列，不納入平均成本。美股歷史買入匯率未紀錄，台幣成本以目前匯率換算。

## 開發模式

需要修改原始碼時，請安裝 Node.js 22 以上版本，再執行：

```bash
pnpm install
pnpm dev
```

建立正式版本：

```bash
pnpm build
```

建置完成後會同時產生 `dist/` 與可直接開啟的 `SmartPortfolio_v1.6.4.html`。

## v1.6.4 Data Safety & Stable Gate

- 本機儲存失敗時持續顯示提示，可重試或匯出畫面資料。讀取失敗時保護原始資料，提供原始檔下載。
- 還原前先保存最近一次復原快照（包含未存成功的畫面變更）；快照寫入失敗就停止覆蓋。可下載快照後重新匯入。
- 快照與主要資料同在此瀏覽器，清除網站資料會一起刪除，不能代替外部 JSON 備份。
- 自動測試涵蓋還原寫入失敗、損毀原文保留及備份往返。實機穩定門檻見 QA_iPhone_PWA_v1.6.4.md，尚待 iPhone 驗收。

## v1.7.0 歷史交易編輯與重算

交易清單提供編輯／刪除，固定原標的與類型；可修改日期、數量、成交價、股息、費用、稅額及備註。確認前顯示數量、平均成本及持股成本前後差異。買賣歷史須與既有持股對齊，否則阻止修改；歷史超賣亦阻止。重算保留即時價格及來源時間，同日維持原登記順序。平均成本不含手續費及稅額，修改成交價不自動改估費用。

每次修改先保存最近一次完整操作前快照，再寫入交易和持股；寫入失敗不套用畫面狀態。快照可於備份下載，再以匯入還原（會覆蓋之後全部變更）。刪除最後一筆買入後保留零股數持股列。已移除持股的買賣紀錄需先恢復對應持股才能編輯；股息可獨立修改。

建置通過；自動測試 30 PASS / 0 FAIL。v1.7.0 新操作尚待使用者實機驗收。

## v1.8.0 實際投資績效

總覽新增原幣已實現淨損益、實收股息、含買入費稅的未實現損益、累計總損益及累計投入報酬率。依交易日重播，售出時按加權平均含費成本分攤。報酬率分母為歷次買入總支出，非年化、IRR 或 TWR。年度只篩選已實現與股息，不冒充年度總報酬。

交易編輯新增費稅已核對與選填 USD/TWD 交易日匯率。舊紀錄保留原費稅估算且一律未核對，不自動猜測歷史匯率。美股台幣損益用歷次現金流匯率與目前參考匯率；缺任一筆則不顯示台幣績效。無銀行實際換匯、股票分割或完整現金帳戶模型。未實現以現有報價估值，並受行情新鮮度限制。

持股成本欄維持既有不含費成交均價；績效為獨立含費計算。履歷與持股未對齊時隱藏該標的績效，避免誤導。新增欄位由 JSON 備份保留。已建置，38 自動測試通過，實機驗收見 QA_v1.8.0.md。
